03 / THE MECHANISMA LEARNED CRITIC. AN EXPLICIT CONTROL LOOP.

Learn the signal.
Optimise the trace.

Encode the goal, contract, accumulated trace, and actual tool results into a state representation. Train a value model to estimate the chance of verified success within a fixed continuation budget.

The controller uses that estimate to select a continuation or revisit an earlier decision. The verifier retains the final say.

WORKING METAPHOR

“Muon for Recursive Optimisation”

A stateful optimiser for agent decisions. Muon inspires the ambition; this prototype does not implement Muon or claim differentiability through tool calls.
